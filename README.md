# Focus List

A polished, dependency-free task manager built as a small demonstration app. Tasks can be added, completed, filtered, and removed, and are saved to browser storage between visits.

## Run locally

```bash
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Test

```bash
npm test
```

The project uses Node's built-in test runner and has no production dependencies.
